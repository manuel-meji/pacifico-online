# Prototipo M5 · Carrito y Pedidos

Abra directamente con su navegador (Chrome, Edge, etc.):
- `1_Abrir_prototipo.html`: Flujo normal de compra.
- `2_Abrir_prototipo_producto_agotado.html`: Alternativa del paso 4 del CU-004 (producto agotado).
- `3_Abrir_prototipo_comercio_suspendido.html`: Alternativa del paso 5 del CU-004 (comercio con membresía suspendida).

### Visualización
- **Versión Web / Escritorio:** Se adapta a pantalla completa con diseño responsivo a dos columnas y resumen fijo.
- **Versión Móvil:** Abra las herramientas de desarrollador (`F12`), active el modo dispositivo (`Ctrl + Shift + M`) y ajuste a 360 px de ancho para visualizar la interfaz móvil con barra fija de acción.

El código fuente modular se encuentra en `frontend/src/modules/M5_Pedidos/`.
